    Linux 平台 Clash Verge Rev 安装与使用教程

    Clash Verge Rev 是一款跨平台的图形化代理客户端，基于 Clash.Meta 核心开发，支持 Windows、macOS 和 Linux 系统。它继承了 Clash 的高性能和灵活性，支持多种代理协议，如 Shadowsocks、VMess、Trojan、Tuic、Hysteria 等，兼容各类机场订阅。Clash Verge Rev 提供现代化的用户界面，配置方式友好，支持多语言、自动订阅更新、节点筛选、分流规则管理等功能。得益于 Meta 内核的增强，Verge 支持更丰富的协议特性与策略组配置，是高级用户与跨境办公场景中的优选工具。本文在 Linux 上讲述如何安装和使用 Clash Verge。

    2.1. 官网地址¶

    Clash Verge Rev 官网下载地址：https://github.com/clash-verge-rev/clash-verge-rev/releases 新手使用建议下载稳定版本，即版本号后标记为 Latest 的版本。

    2.2. 如何选择版本？¶

    在官网下载地址中，有众多版本可供下载，如下表所示，其中文件名当中的数字为版本号，版本号之后跟着的是平台名称及安装包类型。

    package description
    Clash Verge-2.5.2-1.x86_64.rpm Linux RedHat 系列安装包（Fedora、AlmaLinux、Rocky Linux 等，x86_64 64位）
    Clash.Verge-2.5.2-1.aarch64.rpm Linux RedHat 系列安装包（ARM64 架构，如 ARM服务器、开发板等）
    Clash Verge-2.5.2-1.armhfp.rpm Linux RedHat 系列安装包（ARMv7 32位设备）
    Clash Verge_2.5.2_amd64.deb Linux Debian 系列安装包（Ubuntu、Debian、Linux Mint 等，x86_64 64位）
    Clash Verge_2.5.2_arm64.deb Linux Debian 系列安装包（ARM64 架构设备）
    Clash Verge_2.5.2_armhf.deb Linux Debian 系列安装包（ARMv7 32位设备）

    3. Clash Verge Rev 安装¶

    根据自己的芯片类型选择安装程序，这里以 Clash Verge-2.5.2-1.x86_64.rpm 和 Clash Verge_2.5.2_amd64.deb 为例进行安装。

    # 对于 Redhat 系列 Linux 发行版（Centos, Fedora, AlmaLinux, Rocky Linux 等）, 可以使用 rpm 安装包进行安装

curl -L --output /tmp/clash-verge-rev.rpm https://github.dpik.top/https://github.com/clash-verge-rev/clash-verge-rev/releases/download/v2.5.2/Clash.Verge-2.5.2-1.x86_64.rpm

sudo rpm -i /tmp/clash-verge-rev.rpm

# debian 系列发行版（Ubuntu, Mint, MX, Kubuntu, Zorin 等等）, 可以使用 deb 安装包进行安装

curl -L --output  /tmp/clash-verge-rev.deb  https://github.dpik.top/https://github.com/clash-verge-rev/clash-verge-rev/releases/download/v2.5.2/Clash.Verge_2.5.2_amd64.deb
apt-get install -y  /tmp/clash-verge-rev.deb

    4. 导入订阅¶

    先进行 订阅购买 ，获取到订阅链接。订阅链接位于：仪表盘 > 一键订阅 , 然后复制订阅地址或者扫描二维码订阅。

    获取到订阅地址后返回 Clash Verge Rev， 切换到【订阅】页面，再输入框粘贴从机场服务商面板中获得的订阅地址，然后点击导入按钮，经过几秒钟的加载，之后在【代理组】页面就可以看到代理节点即表示导入订阅成功。

    6. 如何彻底卸载 Clash-verge¶

    # 停止并禁用服务
sudo systemctl stop clash-core-service.service
sudo systemctl disable clash-core-service.service

# 删除服务文件
sudo rm -f  /usr/lib/systemd/system/clash-core-service.service


# 重新加载 systemd
sudo systemctl daemon-reload

# 删除软件
sudo dnf remove clash-verge

# 删除配置文件和缓存

rm -rf ~/.config/clash

rm -rf ~/.cache/clash-verge/

rm -rf ~/.local/share/clash-verge/

# 删除窗口状态文件
rm -rf ~/.config/io.github.clash-verge-rev.clash-verge-rev/
# Clash Verge配置文件
rm -rf ~/.config/io.github.clash-verge-rev.clash-verge-rev/verge.yaml
#配置(软件工作)目录：
rm -rf ~/.local/share/io.github.clash-verge-rev.clash-verge-rev/
#订阅(配置)文件目录：
rm -rf ~/.local/share/io.github.clash-verge-rev.clash-verge-rev/profiles/
#重启系统
sudo reboot
