    Linux 平台上 Clash Mi 安装和使用教程

    1. Clash Mi 简介¶

    Clash Mi 是一款基于 Mihomo（Clash.Meta）内核 的多平台网络代理客户端，支持 Windows、macOS、Linux、 Android 和 iOS。它以简洁的界面和强大的分流功能著称，用户可通过导入订阅链接快速加载配置，实现节点切换、规则分流、系统代理和 TUN 模式等功能。UI清新, 简洁不过度设计。 Clash Mi 保留了 Mihomo 内核的高性能与灵活性，同时提供更友好的可视化操作界面，适合新手与进阶用户使用。它常用于机场订阅接入、自建代理管理或网络优化。

    1. 卸载旧版 Clash / Mihomo 客户端（若有），以免配置冲突。

    2. 准备订阅链接，用于导入配置。

    可以导航到 2025 年性价比机场推荐 获取经过精心筛选的机场，避免踩坑。 注册购买订阅后获取到订阅地址。订阅链接通常位于：仪表盘 > 一键订阅 , 然后复制订阅地址或者扫描二维码订阅。

    4. 下载安装 Clash Mi¶

    点击下方按钮下载 v1.0.14.181 版本 （截至2026-01-01最新版本）

    点击下载

    其他版本请访问 官方 GithHub release page 下载

    4.1. rpm 安装方式 (Redhat 系列 Linux 发行版如：Centos, Fedora, AlmaLinux, Rocky Linux 等)¶

    # 下载Clashmi rpm包
wget -O /tmp/clashmi_1.0.14.181_linux_amd64.rpm https://ghfast.top/https://github.com/KaringX/clashmi/releases/download/v1.0.14.181/clashmi_1.0.14.181_linux_amd64.rpm


# 安装 clashmi
sudo dnf install /tmp/clashmi_1.0.14.181_linux_amd64.rpm

# 启动 clashmi
/usr/bin/clashmi

    4.2. apt 安装方式 （适用于 debian 系列发行版 如：Ubuntu, Mint, MX, Kubuntu, Zorin 等等）¶

    对于 debian 系列发行版（Ubuntu, Mint, MX, Kubuntu, Zorin 等等）, 可以使用 deb 安装包进行安装

    # 下载Clashmi debian包
wget -O /tmp/clashmi_1.0.14.181_linux_amd64.deb https://ghfast.top/https://github.com/KaringX/clashmi/releases/download/v1.0.14.181/clashmi_1.0.14.181_linux_amd64.deb

# 安装 clashmi
sudo apt install /tmp/clashmi_1.0.14.181_linux_amd64.deb

# 启动 clashmi
/usr/bin/clashmi

    5. 快速使用/quickstart¶

    1. 选择APP首页菜单我的配置 -> 右上角 ➕ 号按钮 -> 选择添加配置链接
    2. 返回APP首页, 滑动打开连接按钮 ▶️ 即可开始您的科学上网之旅了
    3. 流程截图

    点击➕ 号添加配置

    点击添加配置链接

    将准备阶段获取到的订阅地址输入到配置链接框中，输入一个备注名称

    配置列表

    打开连接

    如果此时弹出错误提示，端口被占用，可能是与其他翻墙软件产生冲突，请关闭其他翻墙软件，然后重试。

    6. 切换节点¶

    如果你的订阅含多个节点：

    • 点击首页的「代理」
    • 进入节点列表
    • 选择你想连接的节点（如 新加坡SG、美国US、香港等）
