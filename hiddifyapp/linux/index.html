    Linux 上安装与配置 HiddifyApp

    HiddifyApp 是一款开源的、跨平台的代理客户端，专门用于加载机场订阅并实现科学上网。它的设计目标是 简单易用 + 高度兼容，适合新手用户，也满足高级用户的自定义需求。支持 Clash、V2Ray、Trojan、Shadowsocks、Hysteria 等多种协议。移动端和桌面端界面统一，方便用户无缝切换，支持多订阅、多配置同时管理。开源透明，代码可审计，支持 TLS/XTLS/Reality 等加密与防探测技术。

    支持的平台包括：

    • Android
    • iOS
    • Windows
    • macOS
    • Linux

    先进行 订阅购买 ，获取到订阅链接。订阅链接位于：仪表盘 > 一键订阅 , 然后复制订阅地址或者扫描二维码订阅。

    3. Hiddify 客户端下载与安装¶

    3.1. 下载地址¶

    • Hiddify Github下载地址：https://github.com/hiddify/hiddify-app/releases

    Github 的下载不稳定，如果下载失败，可以使用Github代理下载。

    3.2. 如何选择版本？¶

    Hiddify 常见版本下载对应版本如下：

    Linux 用户:

    • Hiddify-Linux-x64-AppImage.AppImage: 该版本不需要安装，不依赖系统环境，跨发行版通用，可放 U 盘随身带。推荐非Debian系用户优先选 AppImage。
    • Hiddify-Debian-x64.deb: 该版本只适用于 Debian / Ubuntu 系列linux发行版, 系统集成最好，支持 apt 管理，自动处理依赖。适合Ubuntu / Debian / Linux Mint 用户。
    • Hiddify-Linux-x64-AppImage.tar.gz: 该版本适配所有 Linux发行版，适合进阶用户 / 开发者，不适合新手。

    4. AppImage 安装方式¶

    AppImage是一种用于Linux系统的便携式软件分发格式，其核心设计理念是“一个文件即一个应用程序”。该格式旨在解决Linux生态中因发行版众多（如Ubuntu、Debian、Fedora等）导致的软件包格式不统一问题。‌

    # 下载 Hiddify AppImage包
wget -O /tmp/Hiddify-Linux-x64-AppImage.AppImage https://github.dpik.top/https://github.com/hiddify/hiddify-app/releases/download/v4.1.1/Hiddify-Linux-x64-AppImage.AppImage

# 下载Hiddify 图标，后续创建桌面快捷方式需要用到
wget -O /tmp/Hiddify.ico https://github.dpik.top/https://raw.githubusercontent.com/hiddify/hiddify.com/refs/heads/main/docs/assets/favicon.ico

# 将AppImage复制到 Applications 目录下
cp /tmp/Hiddify-Linux-x64-AppImage.AppImage ~/Applications/Hiddify-Linux-x64-AppImage.AppImage

# 拷贝桌面图标
cp /tmp/Hiddify.ico ~/Applications/Hiddify.ico


chmod u+x ~/Applications/Hiddify-Linux-x64-AppImage.AppImage

# 运行 Hiddify
~/Applications/Hiddify-Linux-x64-AppImage.AppImage

    如果使用 AppImage 方式安装，需要手动创建桌面快捷方式

    vi ~/desktop/Hiddify.desktop

    [Desktop Entry]
Name=Hiddify
Exec=/home/<username>/Applications/Hiddify-Linux-x64-AppImage.AppImage
Icon=/home/<username>/Applications/Hiddify.ico
Terminal=false
Type=Application
Categories=Utility

    注意：需要将<username>替换成实际用户名

    4.1. apt 安装方式 （适用于 debian 系列发行版 如：Ubuntu, Mint, MX, Kubuntu, Zorin 等等）¶

    对于 Debian 系列发行版（Ubuntu, Mint, MX, Kubuntu, Zorin 等等）, 可以使用 deb 安装包进行安装

    # 下载Hiddify debian包
wget -O /tmp/Hiddify-Debian-x64.deb https://github.dpik.top/https://github.com/hiddify/hiddify-app/releases/download/v4.1.1/Hiddify-Debian-x64.deb

# 安装 Hiddify
sudo apt install /tmp/Hiddify-Debian-x64.deb

# 启动 Hiddify
/usr/bin/hiddify

    5. 配置 Hiddify Next¶

    1. 完成下载并安装后双击软件图标打开 Hiddify Next
    2. 选择语言为中文，区域为 中国（别选错）

    3. 导入订阅

      • 方法一：自动识别剪贴板中的 URL
      复制好订阅链接，打开 HiddifyApp，App 会自动识别并提示导入。

点击“导入”即可。
      • 方法二：手动粘贴导入
      在 HiddifyApp 首页右上角点击 ➕（添加配置）

粘贴您的订阅链接，命名，点击“导入”。

    6. 开始使用¶

    回到软件主页，即可看到已经导入的订阅链接，点击下方的 点击连接，即可开始使用。

    您可在软件的 代理 页面看到所有的节点，可通过点击对应的节点进行上网

    建议您选择 香港、 新加坡、日本等亚洲节点，速度快
